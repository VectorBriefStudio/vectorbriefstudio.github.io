Privacy policy

Vector Brief Publisher · last updated 2026-11-22

What this is

Vector Brief Publisher is a private tool that the Vector Brief channel uses to manage its own accounts. It uploads Vector Brief videos to the Vector Brief YouTube channel and Instagram account, and reads those accounts' own analytics. It is not offered to the public, and nobody else can sign in to it.

What data it accesses

  • YouTube: permission to upload videos, read-only access to the channel's account details, and read-only YouTube Analytics reports.
  • Instagram: permission to publish the account's own posts and read the account's own insights.

It only accesses the Vector Brief accounts. It does not access other people's accounts or data.

How the data is used and stored

Access tokens and analytics are stored only on the channel owner's computer. They are used only to publish Vector Brief videos and to measure how they perform. The data is never sold, never shared with third parties, and never used for advertising. Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

YouTube API Services

This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time from your Google Account's third-party connections and from Instagram's settings under Apps and websites. Stored tokens are deleted when access is revoked.
